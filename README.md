# ATOMUM 🤖⚡

Autonomous, self-evolving cloud agent architecture designed for secure local-first execution, iterative self-refactoring, and intelligent background automation.

## 📂 Architecture Overview

- **`core/`**: Central reasoning engine and safety guardrails.
- **`skills/`**: Modular capabilities (Git operations, system tools, API integrations).
- **`memory/`**: Long-term state and vector context management.
- **`CONSTITUTION.md`**: The supreme rules and ethical boundaries governing the agent.
